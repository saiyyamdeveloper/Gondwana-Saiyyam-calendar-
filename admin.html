📦 स्वीकृत परिवर्तन प्रकाशित करें

स्वीकृत = verify-फ़्लैग हटेगा · अस्वीकृत = प्रविष्टि मास्टर डेटाबेस से हटेगी · सभी निर्णय audit-log में दर्ज होंगे। प्रकाशन से data.js + CSV + मास्टर JSON अपने आप पुनर्निर्मित होंगे।

🗄️ संग्रहण — कैलेंडर इमेज · voice · गीत · ऑडियो

हर चीज़ पहले ⏳ candidate बनती है — तीन मार्ग: (1) media/inbox में फ़ाइल डालें (GitHub वेबसाइट से फ़ोन पर भी) → automation स्वचालित विवरण सहित कतार में डाल देता है + Gmail सूचना, (2) 📤 सीधा अपलोड, (3) 🔗 बाहरी लिंक। आपके ✓ सत्यापन के बिना कुछ भी attach/public नहीं होगा।

🧪 नई शोध-प्रविष्टि कतार में जोड़ें (auto-research इनपुट)

शोध से मिला नया शहीद/महापुरुष/क्रांतिकारी/पर्व/स्थल — JSON payload पेस्ट करें। यह केवल कतार में जाएगा; आपकी स्वीकृति के बिना public नहीं होगा।

👥 खाता-प्रबंधन एवं पासवर्ड

मासिक स्वतः रोटेशन + Gmail-डिलीवरी: GitHub Actions workflow (repo secrets SMTP_* आवश्यक)। नया पासवर्ड केवल एक बार दिखता है — सुरक्षित रखें। परिवर्तित credentials प्रकाशित करना न भूलें।
